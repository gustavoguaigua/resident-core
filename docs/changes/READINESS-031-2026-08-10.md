apps, packages, Compose, Prisma y CI son entregables del sprint y no precondiciones para

## 6. Límites y salvaguardas

El `GO` no autoriza:

- entregables runtime asignados a Sprint 1;
- modelos Prisma, migraciones o seeds de dominio;
- autenticación o autorización runtime;
- residentes, propiedades, cuotas, pagos, estados de cuenta, reservas o documentos;
- API o persistencia runtime de Implementation Readiness;
- integraciones productivas, datos reales o secretos reales.

Antes de crear CI o configurar un remoto se debe ejecutar la migración documentada de
`master` a `main`. El baseline documental actual y `AGENTS.md` deben incluirse en un
commit o PR revisado antes o junto con el primer cambio de implementación de Sprint 0.
Estas salvaguardas son tareas del inicio del sprint y no gaps abiertos de readiness.
